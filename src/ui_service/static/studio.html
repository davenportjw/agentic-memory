📖 4-Stage Studio Walkthrough

The main Studio canvas is unanchored so you can work directly with live telemetry and custom memories. Use the guided walkthrough and one-click sample loaders below whenever you want to populate test data.

  1. 1. Ingest & Telemetry: Select a stream in the left FILE / DATA SYSTEM tree, inspect raw turns, and extract candidate memories.
  2. 2. Memory & Categories: Author or edit memories in the left MEMORY EXPLORER or main designer, and resolve ORG > TEAM > AGENT > USER conflicts.
  3. 3. Trigger & Token Eval: Re-test prompts against your memory bank to inspect triggered vs. suppressed rules and token compression.
  4. 4. Spanner Sync & Evolve: Commit staged memories to Cloud Spanner and run AlphaEvolve MAP-Elites across 128d–768d slices.
