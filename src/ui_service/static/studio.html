How test cases & AlphaEvolve work
Test Cases (Run eval): Tests each verification case against live memory retrieval, checking whether expected facts are recalled, forbidden/stale facts are blocked, and org guardrails beat conflicting user preferences.
Auto-Tune (AlphaEvolve): Uses those test cases as a fitness function on gemini-4-neon to evolve embedding size (128d–768d), similarity threshold, confidence gate, dedup threshold, scope weights, and prompt format (ATOMIC_KV, COMPACT_BULLET, FULL_BELIEF)—then lets you apply any winning preset with one click.
