class BigQueryTelemetrySink:
    def log_interaction(self, user_id, session_id, agent_name, event_type, message, payload=None):
        row = {
            "event_timestamp": datetime.datetime.now(datetime.timezone.utc).isoformat(),
            "session_id": session_id,
            "user_id": user_id,
            "agent_name": agent_name,
            "event_type": event_type,  # 'USER_PROMPT' | 'AGENT_RESPONSE'
            "message": message,
            "metadata_json": json.dumps(payload or {}),
        }
        # Async JSON row ingestion into BigQuery adk_agent_telemetry.agent_logs
        errors = self.client.insert_rows_json(self.table_ref, [row])
        if errors:
            logger.error(f"BigQuery insert error: {errors}")

3. Dream Harvest

Summarize BigQuery session logs using AI.GENERATE / ML.GENERATE_TEXT and store learnings in Google Cloud Spanner.

▶️
How to run this state: Click the Run Dream Harvest button above after chatting in State 1. This triggers the AI REM synthesis pipeline to analyze your waking BigQuery logs, distill your profile preferences via BigQuery AI (AI.GENERATE / ML.GENERATE_TEXT), and crystallize them into Google Cloud Spanner.
🌙 Stage 3: REM Synthesis / Dream Harvest
What happens when you click 'Run Dream Harvest': The AI enters an artificial sleep cycle ("REM Synthesis"). It reads all your raw conversation logs from BigQuery, uses BigQuery AI (AI.GENERATE / ML.GENERATE_TEXT) to distill key preferences, extract your single-session intent, and crystallize them into Google Cloud Spanner.
Multi-Session Cross-Session Compaction: When run across multiple sessions, the Dream Engine synthesizes an overarching cross_session_intent, tracks your intent_trajectory as goals evolve over time, and resolves preference conflicts into clean, enduring beliefs in Spanner.
Why "Do AI Agents Dream of Binary Sheep?": Just as biological brains consolidate daytime experiences into permanent memories during sleep, this pipeline converts noisy logs into clean, structured facts in Spanner.
🔍 SQL Queries Executed During Dream Harvest:
  • BigQuery Waking Telemetry Extraction:
    SELECT session_id, user_id, event_type, message, timestamp FROM `adk_agent_telemetry.agent_logs` WHERE session_id = @session_id ORDER BY timestamp ASC;
  • BigQuery AI Batch Synthesizer (ML.GENERATE_TEXT / AI.GENERATE):
    SELECT ml_generate_text_result['content'] AS distilled_preferences FROM ML.GENERATE_TEXT(MODEL `adk_agent_telemetry.gemini_3_5_flash_lite`, (SELECT prompt FROM ...));
  • Cloud Spanner Crystalline Memory Upsert Mutations:
    INSERT OR UPDATE UserPreferences (user_id, preference_key, preference_value, category, confidence, source_session_id, crystallized_belief, keywords, updated_at) VALUES (...);
📜 REM Dream Prompt Sent to Gemini 3.5 Flash Lite:
The AI is prompted with response_mime_type="application/json" and a structured schema instructing it to extract session_intent, intent_category, and crystallize natural language beliefs for every user preference fact.

SELECT session_id, user_id, event_type, message, timestamp
FROM `adk_agent_telemetry.agent_logs`
WHERE session_id = @session_id
ORDER BY timestamp ASC;

-- 2. BigQuery AI Batch Synthesizer Query (ML.GENERATE_TEXT / AI.GENERATE)
SELECT ml_generate_text_result['content'] AS distilled_preferences
FROM ML.GENERATE_TEXT(
  MODEL `adk_agent_telemetry.gemini_3_5_flash_lite`,
  (SELECT CONCAT('Analyze waking logs and distill JSON beliefs:\n', STRING_AGG(message, '\n')) AS prompt
   FROM `adk_agent_telemetry.agent_logs` WHERE session_id = @session_id)
);

-- 3. Cloud Spanner Upsert Mutations
INSERT OR UPDATE UserPreferences (user_id, preference_key, preference_value, category, confidence, source_session_id, crystallized_belief, keywords, updated_at)
VALUES (@user_id, @preference_key, @preference_value, @category, @confidence, @source_session_id, @crystallized_belief, @keywords, PENDING_COMMIT_TIMESTAMP());
2. REM Dream Synthesis Prompt Template Prompt • Gemini 3.5 Flash Lite JSON 
You are an AI REM Memory Synthesizer ("Dream Engine") performing offline memory consolidation over waking conversation logs for user '{user_id}' in session '{session_id}'.
Your goal is to crystallize short-term episodic interactions into clean, accurate, high-confidence long-term semantic beliefs and capture user intent.

Analyze the conversation transcript below:
{full_transcript}

Rules:
1. Extract the user's primary "session_intent": what is the user's underlying goal, motivation, or project focus in this session?
2. Extract the "intent_category": choose one of "onboarding", "exploratory", "architecture_design", "troubleshooting", "profile", or "general".
3. Provide an "intent_confidence" float score between 0.0 and 1.0.
4. Extract every distinct preference, technical skill, job role, favorite language, preferred tool, or identity attribute.
5. NEVER confuse or merge the user's name with their job role.
6. For each preference record, provide: preference_key, preference_value, category, confidence, crystallized_belief, keywords.
7. Also provide a 2-sentence overall profile summary.

Return a valid JSON object matching the required schema.
3. src/pipeline/bq_to_spanner_sync.py Python • Vertex AI & BigQuery AI 
class BqToSpannerSynchronizer:
    def summarize_session_logs(self, session_id: str, user_id: str) -> Dict[str, Any]:
        logs = self.telemetry_sink.get_session_logs(session_id)
        dream_prompt = f"Analyze these waking logs and distill structured JSON beliefs:\n{logs}"

        response = client.models.generate_content(
            model=self.config.model_name,
            contents=dream_prompt,
            config=types.GenerateContentConfig(
                response_mime_type="application/json",
                temperature=0.2,
            ),
        )
        summary = self._parse_summary_json(response.text, user_id, session_id)
        # Crystallize JSON preferences into Cloud Spanner memory table
        self.spanner_client.write_preferences(user_id, summary["preferences"])
        return summary

src/preference_agent/server.py Python • Spanner Fast Cache 
@api.post("/api/preference/query")
async def query_preference_agent(request: ChatRequest):
    start_time = time.time()
    # 1. Primary-Key Cache Lookup in Cloud Spanner (< 10ms)
    facts = spanner_client.get_user_preferences(request.user_id)
    cached_reply = format_multi_fact_spanner_response(request.prompt, facts)
    
    if cached_reply:
        latency_ms = round((time.time() - start_time) * 1000, 2)
        return {
            "response": cached_reply,
            "source": "SPANNER_CACHE",  # Zero LLM token cost
            "latency_ms": latency_ms,     # Typically 4ms – 9ms
        }
    
    # 2. Fallback to full ADK 2.0 reasoning only on cache miss
    return await _fallback_adk_runner(request)
