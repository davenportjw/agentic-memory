1. Live Dialogue: InterviewAgent (Google ADK 2.0)

During conversational sessions, the InterviewAgent executes turns using Google ADK 2.0 and Gemini 3.8 Flash. Facts are captured via tool execution (record_user_answer) without blocking on persistent database writes.

Separation of Dialogue Execution and Memory Distillation

Committing preferences during live conversational turns increases user latency and risks storing contradictory or temporary assertions.

Separating Episodic Logs (BigQuery) from Crystalline Memory (Cloud Spanner) via an offline distillation pass allows the system to validate statements, resolve conflicts across sessions, and produce high-confidence structured records.

BigQuery + Cloud Spanner Dual-Layer Storage

The architecture splits workloads by database engine characteristics:

Google BigQuery provides high-throughput append-only ingestion for conversational traces (USER_PROMPT and AGENT_RESPONSE), supporting full auditability and batch analytics.
Google Cloud Spanner provides sub-10ms primary-key lookups and durable indexed storage, allowing agents to retrieve user preferences immediately without repeating LLM inference.

Queries and Synthesis Pipeline

The synthesis pipeline executes structured queries and invokes Gemini 3.8 Flash with a typed JSON schema:

1. BigQuery Telemetry Extraction: SELECT * FROM `adk_agent_telemetry.agent_logs` WHERE session_id = @session_id ORDER BY timestamp ASC;
2. Synthesis via Gemini 3.8 Flash: genai_client.models.generate_content(model="gemini-3.8-flash", contents=prompt, config=GenerateContentConfig(response_mime_type="application/json"));
3. Cloud Spanner Upsert Mutations: INSERT OR UPDATE UserPreferences (user_id, preference_key, preference_value, category, confidence, source_session_id, crystallized_belief, keywords, updated_at) VALUES (...);
Theoretical & Empirical Foundations

Why Autonomous Agents Must Sleep: \(O(N)\) Context Saturation vs. \(O(1)\) Point-Lookup

Autonomous agents that stay awake indefinitely suffer from quadratic attention latency, context pollution, and runaway token costs. Offline sleep consolidation extracts immutable invariants into Cloud Spanner, collapsing \(O(N)\) token consumption into \(O(1)\) sub-10ms memory point-lookups.

1. The Insomniac Agent (Uncompacted Trajectory) O(N) Complexity

Every interaction re-sends the entire preceding conversation transcript in the prompt window. Attention heads compute cross-attention across thousands of historical tool outputs and transient user chatter.

  • Attention Latency: \(\tau_{\text{TTFT}} = c_0 + \alpha \cdot N + \beta \cdot N^2\)
  • Cumulative Token Cost: \(O(N^2)\) cumulative cost over long tasks
  • Attention Distraction: Hallucination risk escalates as old tools pollute active context
2. The Sleeping Agent (Dual-Contract Spanner Memory) O(1) Complexity

Offline NREM/REM sleep compresses noisy trajectories into certified invariants in Cloud Spanner. Waking agents inject only verified rules via sub-10ms indexed point-lookups.

  • Attention Latency: Flat \(\tau_{\text{lookup}} < 10\text{ ms}\) Spanner fetch + instant agent priming
  • Token Cost: Fixed ~200-300 invariant tokens injected into prompt
  • High Fidelity: Invariants certified with confidence \(\ge 0.85\) and provenance grounding

src/common/telemetry.py: BigQueryTelemetrySink writes events (USER_PROMPT and AGENT_RESPONSE) asynchronously to adk_agent_telemetry.agent_logs.
src/common/telemetry.py 
import datetime
import json
import logging
from google.cloud import bigquery

class BigQueryTelemetrySink:
    def __init__(self, table_id="adk_agent_telemetry.agent_logs"):
        self.client = bigquery.Client()
        self.table_ref = table_id

    def log_interaction(self, user_id: str, session_id: str, agent_name: str,
                        event_type: str, message: str, payload: dict = None):
        """Append conversational event row to BigQuery."""
        row = {
            "timestamp": datetime.datetime.now(datetime.timezone.utc).isoformat(),
            "session_id": session_id,
            "user_id": user_id,
            "agent_name": agent_name,
            "event_type": event_type,  # 'USER_PROMPT' | 'AGENT_RESPONSE'
            "message": message,
            "json_payload": json.dumps(payload or {}),
        }
        errors = self.client.insert_rows_json(self.table_ref, [row])
        if errors:
            logging.error(f"BigQuery ingestion error: {errors}")
src/pipeline/bq_to_spanner_sync.py: Reads session logs from BigQuery, invokes Gemini 3.8 Flash to distill structured beliefs, and writes mutations to Cloud Spanner.
src/pipeline/bq_to_spanner_sync.py 
from google.genai import types
from src.common.config import get_config

class BqToSpannerSynchronizer:
    def sync_to_spanner(self, user_id: str, session_id: str) -> dict:
        # 1. Fetch raw interaction logs from BigQuery
        logs = self.telemetry_sink.get_session_logs(session_id)
        
        # 2. Extract structured beliefs using Gemini 3.8 Flash
        prompt = f"Extract structured beliefs from session logs:\n{logs}"
        response = self.genai_client.models.generate_content(
            model=get_config().model_name,  # gemini-3.8-flash
            contents=prompt,
            config=types.GenerateContentConfig(
                response_mime_type="application/json",
                temperature=0.2,
            ),
        )
        
        summary = self._parse_json(response.text)
        # 3. Write crystallized preferences to Cloud Spanner
        self.spanner_client.write_preferences(user_id, summary["preferences"])
        return summary

src/preference_agent/server.py: Sub-10ms cache lookup. The endpoint inspects Spanner preferences first; on a cache hit, it responds without invoking LLM inference.
src/preference_agent/server.py 
@api.post("/api/preference/query")
async def query_preference_agent(request: ChatRequest):
    start_time = time.time()
    
    # 1. Primary-key / vector lookup in Cloud Spanner (< 10ms)
    matched_records = _multi_method_spanner_retrieval(
        user_id=request.user_id, prompt=request.prompt, client=spanner_client
    )
    
    if matched_records:
        latency_ms = round((time.time() - start_time) * 1000, 2)
        response_text = format_multi_fact_spanner_response(matched_records, latency_ms)
        
        return {
            "response": response_text,
            "source": "SPANNER_CACHE",  # Zero LLM overhead
            "latency_ms": latency_ms,     # Sub-10ms point lookup
            "spanner_record": matched_records[0],
        }
    
    # 2. Fallback to ADK 2.0 reasoning only on cache miss
    return await _fallback_adk_runner(request)
