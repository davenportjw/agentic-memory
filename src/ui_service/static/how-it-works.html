Do AI Agents Dream of Binary Sheep?

Multi-agent memory architecture built on Google ADK 2.0 and Gemini 3.8 Flash: append-only session logs distill offline into indexed preferences for sub-10ms recall.

Step 1: Session Logs

BigQuery · agent_logs

Conversation events append asynchronously to adk_agent_telemetry.agent_logs without blocking live replies.

Schema SQL 
CREATE TABLE `adk_agent_telemetry.agent_logs` (
  timestamp TIMESTAMP NOT NULL,
  user_id STRING NOT NULL,
  session_id STRING NOT NULL,
  agent_name STRING NOT NULL,
  event_type STRING NOT NULL,
  message STRING,
  json_payload JSON
)
PARTITION BY DATE(timestamp)
CLUSTER BY user_id, session_id;

System Topology

1. InterviewAgent

Captures user facts via record_user_answer without blocking on synchronous database commits.

Offline Consolidation

Separating append-only session logs from durable preferences lets offline synthesis resolve contradictions before committing high-confidence rules.

Dual Storage Tiers

BigQuery handles high-throughput event ingestion while Cloud Spanner serves sub-10ms indexed preference lookups.

Context Replay vs. Indexed Lookup

Replay tokens: 37,500 · Replay TTFT: 700 ms · Lookup: < 8 ms · Compaction: 99.2%
Full-History Replay (O(N))

Re-sending every historical turn grows token cost and latency with session length.

Indexed Rule Lookup (O(1))

Injects only verified rules (~200–300 tokens) via sub-10ms primary-key lookup.

from google.adk.agents import Agent
from src.common.config import get_config

def record_user_answer(user_id: str, question: str, answer: str) -> str:
    return f"Fact recorded: {question} = {answer}"

agent = Agent(

    model=get_config().model_name,  # gemini-3.8-flash

    def log_interaction(self, user_id: str, session_id: str, agent_name: str,
                        event_type: str, message: str, payload: dict = None):
        row = {"user_id": user_id, "session_id": session_id, "event_type": event_type, "message": message}

src/pipeline/bq_to_spanner_sync.py 
class BqToSpannerSynchronizer:
    def sync_to_spanner(self, user_id: str, session_id: str) -> dict:
        logs = self.telemetry_sink.get_session_logs(session_id)
        response = self.genai_client.models.generate_content(
            model=get_config().model_name,  # gemini-3.8-flash
            contents=f"Extract structured beliefs:\n{logs}",
        )
        summary = self._parse_json(response.text)
        self.spanner_client.write_preferences(user_id, summary["preferences"])
        return summary
